# PPT 幻灯片生成

当用户要求制作 PPT、幻灯片、演示文稿、汇报 deck、路演材料或把内容转换为 `.pptx` 时，使用本技能。

## 工作方式

1. 先理解用户的主题、受众、页数、语言、视觉风格和交付格式。
2. 如果主题需要事实、案例、人物、品牌、图片素材或近期信息，先进行资料收集，并保留关键信息来源。
3. 先设计整套幻灯片结构：封面、目录/叙事线、主体页、数据/案例页、总结页。
4. 为每页生成高质量视觉稿，优先使用 HTML/CSS 表达版式：
   - 16:9 宽屏；
   - 大标题、强对比、留白、网格系统；
   - 卡片、图表、时间线、人物/产品视觉、背景渐变等；
   - 中文默认使用微软雅黑或系统中文字体；
   - 避免密密麻麻的正文堆砌。
5. 将幻灯片导出为可编辑 `.pptx`，尽量保留文字、图片、形状、表格等对象的可编辑性。
6. 如果转换保真度不足，要如实说明哪些元素是截图背景、哪些元素是可编辑对象，不要声称已经达到完美还原。

## 输出要求

- 默认生成中文 PPT，除非用户指定其他语言。
- 默认追求高级视觉效果，而不是普通文档式排版。
- 每页标题应简洁有冲击力；正文少而精。
- 图片素材要和主题强相关；不要使用无关装饰图。
- 最终应交付 `.pptx` 文件路径，并简要说明页数和主要内容。

## 限制

当前 VeryAgent 的 HTML 到 PPTX 转换能力仍在迭代中。复杂 CSS、动画、滤镜、混合模式等效果可能无法全部转换为原生 PPT 对象；必要时可以使用截图背景作为视觉保真兜底，同时叠加可编辑文本和图片。
